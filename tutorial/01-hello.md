# Day 1：让程序跑起来

**今天不谈项目，只做一件事：确认你的电脑能写 C++、能编译、能运行。**

用时：约 1.5–2 小时。

---

## 1.1 检查 Visual Studio（10 分钟）

打开「Visual Studio Installer」（开始菜单搜一下）。

看已安装的实例右边有没有 **「使用 C++ 的桌面开发」** 这个工作负载。

- 有 → 下一步
- 没有 → 点「修改」→ 勾选它 → 点右下角「修改」→ 等 10–20 分钟

> 这一步不做好，后面所有事都做不了。

---

## 1.2 新建一个项目（10 分钟）

1. 打开 Visual Studio
2. 选 **「创建新项目」**
3. 搜索框输入 `空项目`，选 **「空项目」**（C++，不是 C#），点下一步
4. 填写：
   - 项目名称：`ChunkReader`
   - 位置：`D:\cpp`（或者你喜欢的目录，**路径不要有中文和空格**）
5. 点「创建」

你会看到一个空白的界面，右边有「解决方案资源管理器」。

---

## 1.3 添加一个源文件（5 分钟）

1. 右侧「解决方案资源管理器」里找到 **「源文件」** 文件夹
2. 右键 → **添加** → **新建项**
3. 选 **「C++ 文件(.cpp)」**，名字填 `main.cpp`，点「添加」

---

## 1.4 写第一段代码（5 分钟）

把下面这段**一字不差**地敲进去（不要复制粘贴，第一次要练手感）：

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, ChunkReader!\n";
    return 0;
}
```

逐行解释：

| 行 | 含义 |
|---|---|
| `#include <iostream>` | 引入输入输出库，`std::cout` 就在里面 |
| `int main()` | 程序的入口，操作系统从这里开始执行 |
| `std::cout << "..."` | 把字符串送到屏幕 |
| `\n` | 换行符 |
| `return 0;` | 告诉系统“正常结束”，0 表示成功 |

---

## 1.5 运行（2 分钟）

按 **`Ctrl + F5`**（开始执行不调试）。

应该弹出一个黑窗口，显示：

```
Hello, ChunkReader!
请按任意键继续. . .
```

**看到这行字，今天最重要的事就完成了。**

> 为什么用 `Ctrl+F5` 而不是 `F5`？`F5` 是调试模式，程序结束会立刻关窗口，你什么都看不到。

---

## 1.6 故意制造一个错误（10 分钟，很重要）

把 `std::cout << "Hello, ChunkReader!\n";` 这一行**末尾的分号删掉**，再按 `Ctrl+F5`。

你会看到「错误列表」里出现一条：

```
错误  C2143  语法错误: 缺少“;”(在“return”的前面)
```

双击这条错误，光标会跳到出问题的地方。

**这就是你未来三周最常打交道的界面。** 要学会：

1. 看**第一条**错误（后面的错误往往是连锁反应）
2. 双击跳转到代码
3. 错误信息里的行号是**出错位置的下一个 token**，真正的错误通常在这一行或上一行

改回来，确认能运行。

### 再试一个

把 `int main()` 改成 `int mian()`，编译。报的是：

```
错误  LNK2019  无法解析的外部符号 main
```

这是**链接错误**，不是语法错误。区别很重要：

| 阶段 | 错误前缀 | 意思 |
|---|---|---|
| 编译 | `C####` | 代码写错了（语法、类型） |
| 链接 | `LNK####` | 函数/变量找不到（拼写、缺文件、缺库） |

## 1.7 理解程序是怎么变成 .exe 的（10 分钟）

```
main.cpp
   │  ① 预处理：把 #include 的内容展开进来
   ▼
main.i（你看不到）
   │  ② 编译：翻译成机器码
   ▼
main.obj
   │  ③ 链接：把 obj 和库拼起来
   ▼
ChunkReader.exe
   │  ④ 运行
   ▼
黑窗口
```

**为什么现在讲这个**：后面你会遇到“明明写了函数却链接不到”（忘了把 `.cpp` 加进项目）、“改了头文件没生效”这些问题，知道这四个阶段就不会慌。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 搜不到「空项目」 | 没装「使用 C++ 的桌面开发」工作负载 |
| 黑窗口一闪而过 | 用了 F5；改用 `Ctrl+F5` |
| 中文显示成乱码 | 今天全英文，先不管；Day 2 会处理 |
| 提示“无法启动程序” | 上一次编译失败，先看错误列表 |
| 改了代码没生效 | 编译没成功，或运行的是旧 exe；重新生成解决方案 |
