# 三周作战地图

> 适用：C++ 第一学期、零项目经验、Windows + Visual Studio。
> 每天 2–3 小时。做不完就顺延，**不要跳步**。

## 三条铁律

1. **每一步都运行一次**。不要写完 200 行才编译。
2. **卡住 30 分钟就问我**，把完整报错贴过来（别只说"报错了"）。
3. **每天结束提交一次**（哪怕只是 `git commit -m "day1"`）。

---

## 第 1 周：把链路跑通

| 天 | 主题 | 你会学到 | 当天产出 | 验收标准 |
|---|---|---|---|---|
| D1 | 环境与第一个程序 | VS 使用、编译链接 | Hello 程序 | 能独立新建项目并运行 |
| D2 | 读文件 | `ifstream`、`string`、`getline` | `io.cpp` | 打印出文件的行数和字符数 |
| D3 | 分词 v1 | 循环、`vector`、`string` 操作 | `text.cpp` | `"Hello, world!"` 切成 4 个词 |
| D4 | 结构体与标点 | `struct`、`enum`、函数拆分 | `token.h` | 每个 Token 带类型和位置 |
| D5 | 输出 JSON | 转义、`ostream` | `main.cpp` 的 `--json` | 用 Python 能解析输出 |
| D6 | Python 前端 | 跨进程、编码 | `engine.py` | 点"打开文件"能看到界面渲染 |
| D7 | 复盘与提交 | git、`cloc` | 打 tag `v0.2` | 代码入库，行数有数 |

**D7 里程碑**：`chunkreader --json` 能输出合法 JSON，Python 能显示（虽然是按空格切的假语块）。

## 每天固定动作（10 分钟）

1. 开始前：`git status`，确认昨天的东西还在
2. 结束后：编译一次 + 运行一次 + `git commit`
3. 在 `docs/log.md` 写 3 行：今天做了什么 / 卡在哪 / 明天第一件事
